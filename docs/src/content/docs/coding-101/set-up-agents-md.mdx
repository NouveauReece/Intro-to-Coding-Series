## Sections of an Agents MD
Anything really! But just like a human, we should probably fill in our LLM about:
1. The LLM's "role" (are they a designer? developer? teacher?)
2. Project Goals
3. Very Specific Styles/Themes
4. Coding languages, coding style, file structure
5. How you want the LLM to behave
6. Do's and Don'ts
