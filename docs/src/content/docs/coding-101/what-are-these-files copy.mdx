## Warning!
It's easy for Codex (or another LLM) to produce a lot of code without involving you in the process. *You need to know what it generates and how it works!* **Always include in your prompt asking how things work and how to plan things out**

## 1. Explain/Reason Thru It
It's important to know our options before it goes and generates slop. Ask some leading questions:

<blockquote>How might I make ________ using my HTML file?</blockquote>
<blockquote>Where in my CSS file would I change the colour of ______?</blockquote>
<blockquote>Walk me through how we can could implement ______.</blockquote>
<blockquote>Consider how we would make _____. What are different ways we could code it? What are the pros and cons?</blockquote>

## 2. Align It with your Vision
<blockquote>Ask me a few questions about _____ to make sure we're on the same page.</blockquote>
<blockquote>Search the web for images of ______ and consider how we could make the background look like them.</blockquote>
<blockquote>[Attach image] here's the vibe I want. Notice _____, ______, and _____ from the sample image. I want a similar font/layout/colours/aesthetic</blockquote>

## 3. Understand it!
<blockquote>Explain in simple language what you just did?</blockquote>
<blockquote>What does [paste code] mean? Explain what it is and how it works</blockquote>
